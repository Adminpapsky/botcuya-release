## ✨ Tentang BOT-CUYA

**BOT-CUYA** adalah aplikasi Android untuk menjalankan bot WhatsApp. Repositori ini merupakan kanal resmi distribusi APK dan informasi pembaruan BOT-CUYA.

Kami berupaya menyediakan pengalaman penggunaan yang praktis, disertai informasi versi dan pembaruan aplikasi agar pengguna dapat menggunakan versi yang sesuai.

## 🧭 Cara memasang

1. Buka halaman [rilis terbaru](https://github.com/Adminpapsky/botcuya-release/releases/latest).
2. Unduh file **BOT-CUYA.apk**.
3. Buka file APK yang sudah diunduh pada perangkat Android.
4. Jika Android meminta izin untuk memasang aplikasi dari sumber tersebut, tinjau dan izinkan sesuai pengaturan perangkat.
5. Selesaikan pemasangan, lalu buka BOT-CUYA.

Nama menu dan langkah izin dapat berbeda tergantung versi Android dan merek perangkat.

## 🔔 Pembaruan aplikasi

BOT-CUYA memiliki mekanisme pemberitahuan pembaruan. Jika versi baru tersedia, pengguna dapat menerima informasi pembaruan melalui aplikasi.

Untuk menjaga kompatibilitas dan keamanan:
- Periksa informasi versi dan catatan perubahan pada halaman **Releases**.
- Gunakan versi terbaru yang diterbitkan melalui kanal resmi.
- Jika pembaruan ditandai wajib oleh aplikasi, ikuti petunjuk pembaruan sebelum melanjutkan penggunaan.
- Jangan memasang APK yang tautan atau asal-usulnya tidak dapat diverifikasi.

**Riwayat versi:** [Lihat semua catatan rilis](https://github.com/Adminpapsky/botcuya-release/releases).

## 🛡️ Keamanan dan penggunaan

- Pastikan file berasal dari kanal resmi BOT-CUYA.
- Jangan membagikan kode verifikasi WhatsApp, PIN, kata sandi, atau informasi akun kepada siapa pun.
- Amankan perangkat dan akun WhatsApp yang digunakan.
- Gunakan bot secara bertanggung jawab dan patuhi ketentuan layanan WhatsApp serta hukum yang berlaku.
- Fitur dan ketersediaan dapat berubah mengikuti pembaruan aplikasi.
